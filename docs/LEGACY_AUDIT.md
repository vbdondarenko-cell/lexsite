# Аудит чинного сайту lex.ck.ua

Дата знімка: 2026-11-04. Метод: пряме завантаження HTML (`docs/legacy-original/index.html`), витяг видимого тексту.

## Технічні факти
- Конструктор **Weblium**; сайт — **одна сторінка** з якорями `#cover-1`, `#about-me`, `#services`, `#contacts`. Окремих URL послуг/справ/відгуків **немає**.
- `robots.txt`: `User-agent: *`, `Disallow: /.sw_/_host_/_replacer_`, `Sitemap: https://lex.ck.ua/sitemap.xml`.
- `sitemap.xml` — індекс із одним вкладеним `sitemap_pages.xml` (lastmod 2026-10-28). Вміст вкладеного sitemap **не перевірявся окремо**.
- Усі зображення — з CDN Weblium (`res2.weblium.site`); 19 файлів завантажено при аудиті, **права на фото невідомі** (див. CONTENT_APPROVAL).
- Контактні імейли в HTML записані задом наперед (захист від ботів). Розшифровано: `ex_lege@i.ua`, `advokat_davydiuk@ukr.net` — **потребують підтвердження**.
- Приховані блоки: кнопки «БІЛЬШЕ» лише розгортають вже присутній у HTML перелік. Інших прихованих текстів не виявлено.
- Англомовні службові рядки форми (`Thank you!`, `Can't send form.`) — залишки шаблону.

## Не перевірено (чесно)
- Поведінка форми чинного сайту, і куди вона реально доставляє заявки.
- Вміст `sitemap_pages.xml`, метадані (title/description) окремо від тексту сторінки.
- Візуальне порівняння у браузері.

## Інформаційна архітектура: було → стало
Одна сторінка → 11 маршрутів + 22 сторінки послуг + 6 справ + системні (404, помилка, `/dyakuiemo`).
